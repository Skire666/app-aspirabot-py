Un jour, faire un extractor dédié.

Dans l'idée : Dans mon scénario, j'ajoute UNE SEULE brique extractor.
Cette extractor est un panneau dédié.

Dedans, il y une liste de sous-extractor (exemple avec youtube) :
- les infos basique
- le yt-dlp complet
- les SRT.

Je peux ajouter un sous-extractor comme je le souhaite :
- Soit un existant (comme yt-dlp) ou alors un custom (avec le JS)
- Un sous-extractor possède un préfixe de GROUPE. Genre chaque "nom de colonne" est préfixé automatiquement avec. C'est genre un alphanum entre 1 et 16 de long
- Une fois dans l'export CSV, cette histoire de groupe ça donne "groupe.colonne_a ; groupe.colonne_B", "groupe.colonne_c".
- Chacun export/extract gère ses propres colonnes (les "publiques", exemple, yt-dlp c'est le champs de l'objet, et js_custom, c'est le return à la fin).
- NOTE PCO : le js_custom, il n'est pas vérifié, mais on pourrait forcer la présence d'un retourne, et gérer les "clés" retournée à la fin. Augmente ainsi la vérification, j'extrapole les colonnes, et puis je force une certaine implémentation.
- Chacun à sa propre méta données (date_created, date_modified, date_session, quality_row, quality_date) + AJOTUER LE PREFIXE DE GROUPE.
- je vois tpites les colonnes que renvoie le sous-extract (préfixe de groupe + méta-donnée + colone publiques)

Comportement général :
- Les extractors s'éxécute dans l'ordre que j'ai déclaré.
- Chacun peut faire des vérifs basiques avant l'exécution de l'extracteur (genre si la page est la, telle sélecteur CSS est bien disponible)
- Une fois la donnée extraire MAIS AVANT la maj du tableau : vérifier si tel valeur est bien disponible, ou que la qualité d'une ligne ne vas pas régresser de plus X points, que tel colonne doivent etre une date ISO, etc...
- Les colonnes des extracteurs sont toujours "rangées" dans son préfixe de groupe. Ainsi, je peux avoir plusieurs "date_created" car chacun extractor va faire "groupe_a.date_created", "groupe_b.date_created", "groupe_c.date_created", donc je les distingues tous.
- Comme j'ai tous les extracteurs, je peux voir toutes les colonnes que va posséder mon CSV (métadonnées y compris).
